Open-source software

spaceback for Android, iPhone and iPad is built with the open-source software listed on this page. Thank you to everyone who wrote it.

FFmpeg

spaceback uses the FFmpeg libraries, version 8.1.2, to read and compress videos. This software uses libraries from the FFmpeg project under the GNU Lesser General Public License, version 3 or later. That licence is a set of permissions added to the GNU General Public License, version 3, whose text applies with it. FFmpeg is owned by its authors, not by spaceback.

The libraries are built without any change of ours, with no GPL or non-free component enabled, and are shipped as separate shared libraries that the app loads when it runs.

The source code they are built from:

  • FFmpeg: github.com/arthenica/FFmpeg, tag n8.1.2.
  • Build scripts: github.com/arthenica/ffmpeg-kit-next, tag v8.1.0.
  • Android build: ./nix-android.sh -p android-r27d --disable-arm-v7a --disable-arm-v7a-neon --disable-x86 --enable-libsvtav1 --enable-android-media-codec
  • iPhone and iPad build: ./nix-ios.sh -p xcode26 -x --spm --disable-arm64e --disable-x86-64-mac-catalyst --disable-arm64-mac-catalyst --disable-x86-64 --enable-libsvtav1 --enable-ios-videotoolbox

If you cannot reach these, write to little.big69@icloud.com and we will send you the source code.

FFmpegKit

ffmpeg-kit-next 8.1.0 is what runs FFmpeg inside the app. It is licensed under the GNU Lesser General Public License, version 3. Its source is the repository above, at the same tag.
